# Security

Anasing is currently beta software. Report security vulnerabilities using this repository's private security reporting feature when the publisher has enabled it. Avoid putting sensitive reproduction files, credentials, or exploit details in a public issue.

The project does not ask users to disable Gatekeeper, remove quarantine attributes, or weaken macOS security. Public binary releases should be Developer ID-signed and notarized.

Archive extraction rejects traversal paths, symlinks, hardlinks, and special files. Conversions create new outputs and preserve sources. Parser libraries still process untrusted file content; keep the packaged engines updated and test each update.
